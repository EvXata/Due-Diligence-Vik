# Deal Evidence Graph Local Product

Static localhost prototype for the DD/GTM Discovery product:

- One `Deal Evidence Graph`.
- Nine role-native interfaces.
- DD tournament vector deals filtered to bear/bull/deep-audit style work.
- BCG-team v9 / Unified MAS workflow mapping.

Run locally:

```bash
python3 -m http.server 4173
```

Open:

```text
http://localhost:4173
```
